# Shahziar Karim Safit — Personal Research Portfolio

## Run locally
1. Extract this folder.
2. Open `index.html` in Chrome, or use VS Code + Live Server.
3. The five newly supplied research PDFs are linked from the Publications section.
4. `CV.pdf` is linked from the View CV button.
